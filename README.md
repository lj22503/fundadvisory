# fundadvisory

AI + 基金投顾实战 demo。

## 本仓库说明

本仓库**仅含静态成品**（`index.html` + `css/` + `js/`），所有内容已直接嵌入 HTML / CSS / JavaScript 文件本体。

- 原始生成代码 / 模板源不可用
- 后续可改动范围：HTML 文案、CSS 样式、JS 数据（`js/data.js`）
- 重大重构或新增功能需从头重做

## 文件结构

```
fundadvisory/
├── README.md       # 本说明
├── index.html      # 智投AI demo 主页面（16.8KB）
├── css/
│   └── style.css
└── js/
    ├── app.js
    └── data.js
```

## 技术栈

- 纯 HTML + CSS + 原生 JavaScript
- 图表：[Chart.js](https://www.chartjs.org/)（CDN）
- 图标：[Font Awesome 6.4.0](https://fontawesome.com)（CDN）

## 部署

仓库根目录直接放 GitHub Pages 即可，无构建步骤。
